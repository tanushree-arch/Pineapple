# Mission Pineapple 🍍

Current build:

1. User-provided cinematic intro video plays first.
2. The intro is shown once and can be skipped.
3. The first three original images are shown unchanged.
4. Song 1 (`Forever`) plays continuously across the three images after user interaction.
5. Song 1 fades out at the end of the third image.

Assets:
- `assets/intro.mp4`
- `assets/slide1.png`
- `assets/slide2.png`
- `assets/slide3.png`
- `assets/song1.mp3`

Open `index.html` locally or with VS Code Live Server.

Future chapters will be added to the same project.
